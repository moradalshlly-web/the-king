## 1️⃣ MOROAI Studio — استوديو الإنتاج (الأعلى أولوية)

**لماذا الأول؟** لأنه **الأساس** — كل وحدة أخرى تحتاجه.

### المهام
- إنتاج النصوص (روايات، كتب، وثائق)
- إنتاج الصوت (دبلجة، TTS، محاكاة أصوات)
- إنتاج الموسيقى
- إنتاج الفيديو (سينمائي، قصير، حسب منصات)
- إنتاج الأنمي (من مانجا/مانهوا)
- القوالب الجاهزة (فيديو + كود)

### الوكلاء تحت Studio
| الوكيل | التخصص |
|---|---|
| `text_writer` | كتابة النصوص الطويلة |
| `voice_actor` | توليد الصوت الواقعي |
| `music_composer` | تأليف الموسيقى |
| `video_director` | تنسيق المشاهد |
| `anime_creator` | من مانجا إلى أنمي |

### آلية العمل
1. المستخدم يكتب طلباً في Chat
2. MOROAI يفكّك الطلب
3. يوزّعه على وكلاء Studio المتخصصين
4. كل وكيل يُقارن نفسه بمشروع مفتوح المصدر
5. يحفظ الفرق في ذاكرته
6. يطوّر نفسه حتى التطابق أو تجاوزه
7. يعرض النتيجة للمستخدم للموافقة

**معيار إتمام Studio:**
- ✅ 5 وكلاء متخصصين يعملون
- ✅ كل وكيل له workspace وذاكرة
- ✅ المستخدم يرى النتائج بجودة عالية
- ✅ Studio يعمل تلقائياً بلا تدخل يدوي

## 2️⃣ MOROAI Learn — منصة التعلّم (الثانية)

**لماذا الثانية؟** لأنها تحتاج Studio (لإنتاج المحتوى التعليمي).

### المهام
- البحث عن كورسات ومهارات
- ميزة "ادرس معي"
- رفع كتب/صور/دروس
- اختبارات وبطاقات تعليمية
- تتبّع التقدم

### الوكلاء تحت Learn
| الوكيل | التخصص |
|---|---|
| `curriculum_designer` | تصميم المناهج |
| `quiz_maker` | إنشاء الاختبارات |
| `study_buddy` | المرافقة في التعلّم |
| `progress_tracker` | متابعة التقدم |

**معيار إتمام Learn:**
- ✅ 4 وكلاء يعملون
- ✅ المستخدم يتعلّم عبر المنصة
- ✅ المحتوى من Studio

---

## 3️⃣ MOROAI Gamer — بناء الألعاب (الثالثة)

**لماذا الثالثة؟** تحتاج Studio كاملاً (فيديو، صوت، صور، 3D).

### المهام
- بناء ألعاب 2D
- بناء ألعاب 3D
- ألعاب PPSSPP
- ألعاب مع AI مدمج
- تحويل روايات إلى ألعاب

### الوكلاء تحت Gamer
| الوكيل | التخصص |
|---|---|
| `novel_to_game` | من رواية إلى لعبة |
| `character_builder` | بناء الشخصيات 3D |
| `scene_builder` | بناء المشاهد |
| `gameplay_designer` | تصميم أسلوب اللعب |
| `optimizer` | تحسين للأجهزة الضعيفة |

**معيار إتمام Gamer:**
- ✅ 5 وكلاء يعملون
- ✅ لعبة كاملة تعمل على Android متوسط
- ✅ المستخدم يلعب ويقيّم

## 4️⃣ MOROAI Build — بناء المشاريع (الرابعة)

**لماذا الأخيرة؟** تحتاج كل ما سبق.

### المهام
- بناء مواقع كاملة
- بناء تطبيقات
- بناء APIs
- بناء أنظمة كاملة (multi-file)
- ترحيل ونشر

### الوكلاء تحت Build
| الوكيل | التخصص |
|---|---|
| `architect` | تصميم المعمار |
| `frontend_dev` | الواجهات |
| `backend_dev` | الخوادم |
| `devops` | النشر والصيانة |

**معيار إتمام Build:**
- ✅ 4 وكلاء يعملون
- ✅ بناء مشروع كامل من الصفر
- ✅ النشر يعمل تلقائياً
